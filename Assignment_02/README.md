# CampusWheels Vehicle Rental System

## How to Run

1. Open terminal in this folder.
2. Run:

python main.py


## Files

- rental.py : Contains Vehicle, Renter, ElectricCar and Motorbike classes.
- main.py : Demonstrates creating objects, renting, returning and error handling.
